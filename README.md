# 🧠 Classificação e Otimização de Redes Neurais (MLP)

> **Resumo do Projeto:** Uma análise científica sobre como o número de neurônios e as funções de ativação influenciam a inteligência de uma rede neural utilizando a base de dados Iris.

## 🛠️ Tecnologias e Bibliotecas Utilizadas
* **Python** (Linguagem base)
* **Pandas** (Estruturação da tabela de resultados do GridSearch)
* **Scikit-Learn** (Construção do MLPClassifier e automação com GridSearchCV)
* **Matplotlib & Seaborn** (Geração dos gráficos de desempenho e matriz de confusão)
* **HTML/CSS** (Desenvolvimento da estrutura visual dos slides)
